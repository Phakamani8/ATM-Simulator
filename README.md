# ATM Simulator

A simple ATM simulator built with Python. The program allows a user to log in with a PIN and perform basic banking operations through a command-line interface.

### Features

* PIN authentication with a maximum of 3 attempts
* View current balance
* Withdraw money
* Deposit money
* Input validation and error handling
* Card blocking after 3 incorrect PIN attempts
* Exit the program safely

* `try/except` error handling
